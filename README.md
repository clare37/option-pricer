# Black-Scholes & Monte Carlo Option Pricer

Interactive tool that prices European options two ways: the Black-Scholes closed-form formula and Monte Carlo simulation (with antithetic variates for variance reduction). Pricing accuracy within 0.02% of the analytical benchmark at 100,000 simulations.

Built with Python (NumPy, SciPy, Matplotlib) and Streamlit.

Run locally: `streamlit run proj_streamlit.py`
